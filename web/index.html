System One in your browser

Jeyzma

Typed decisions with calibrated probabilities, from one forward pass and with no generated text.

A System One model answers a typed question about a state. It gives a probability for each option instead of writing an answer. This page runs the model completely in the local browser using WebAssembly. There is no server, no API key, and no data goes anywhere.
