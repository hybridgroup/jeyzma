System One in your browser

Jeyzma

Go make a decision! Run System One models, 100% local in your browser using WebAssembly written in Go.

A System One model answers a typed question about a state. It gives a probability for each option instead of writing an answer. This page runs all inference in your browser using yzma compiled with TinyGo. There is no server, no API key, and no data goes anywhere.
