Jeyzma looking for a backend

This page runs a System One model completely in the local browser using WebAssembly. There is no server, no API key, and no data goes anywhere. The model answers typed questions about a state with a probability for each option, from one forward pass and with no generated text. Uses GPU with WebGPU when available, otherwise uses CPU. Written in Go using yzma on TinyGo. Source code is available here.
